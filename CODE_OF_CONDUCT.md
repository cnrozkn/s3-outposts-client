# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful in issues, pull requests and reviews. Harassment, insults and personal attacks are not
accepted.

To report unacceptable behavior privately, use **Report content** in the menu of the comment, issue or pull
request; the report goes to GitHub's support team. The maintainer may hide or remove content, lock
conversations and block accounts that break this code.
